# 海鲜档口活鲜暂养与损耗结算平台

面向海鲜档口的活鲜暂养管理：档口 / 水槽 / 品种批次 / 入池称重 / 暂养记录 /
订单分拣 / 死亡报损 / 供应商结算。**纯 Python 标准库实现，零第三方依赖**
（`http.server` + `sqlite3` + `threading`），SQLite 保存批次与称重数据。

## 一条命令本地启动

```bash
./run.sh                 # 或 bash run.sh，默认 8000 端口
./run.sh 9000            # 指定端口
# 等价于：
python3 -m seafood.app --demo
```

`--demo` 会重置数据库并自动生成样例：6 次入池（青斑鱼/花蟹/生蚝/对虾/鲈鱼）、
1 张已完成订单（分拣出池）、1 笔死亡报损、1 笔补录称重差异挂账。
浏览器打开 http://localhost:8000 即为六页签工作台。

其他启动方式：

```bash
python3 -m seafood.app                  # 使用已有 seafood.db，不重置
python3 -m seafood.app --reset          # 清空业务数据
python3 -m seafood.app --no-monitor     # 关闭每 5 秒的探头后台轮询
python3 -m unittest tests.test_platform # 运行全部规则测试（16 项）
```

## 功能与页签

| 页签 | 内容 |
|---|---|
| 水槽看板 | 按 A/B/C 区域排列；显示容量占用条、实时水温/溶氧、各批次**大号数字**剩余重量；异常水槽红框 + 闪烁角标 |
| 批次入池 | 入池表单（品种/规格/来源批次/重量/水槽），自动校验**容量、盐度、混养冲突**；批次列表可补录称重 |
| 暂养记录 | 水温/溶氧历史；可向指定水槽**注入「升温 / 缺氧」工况**观察告警 |
| 订单分拣 | 按在池批次下单锁定数量；确认出池 / 取消释放；内置「两员工同时抢同一批次」演示按钮 |
| 损耗处置 | 死亡/缺氧/逃逸/失重报损，**必须关联原批次**；SVG 虚线展示「损耗记录 ↔ 原批次」连线关系 |
| 供应商对账 | 来源批次生成对账单、差异挂账确认、供应商凭证确认结算；已结算批次重量锁定 |

所有页签顶部都有**固定警示位**（sticky），水温异常 / 缺氧 / 混养冲突 /
称重差异 / 订单取消 / 死亡率超阈值统一钉红显示，直至人工处理。

## 关键业务规则

- **入池校验**：盐度要求按品种匹配水槽；现存重量 + 本次重量不得超过水槽容量；
  与槽内既有品种的混养冲突对会拒绝入池并记严重告警。
- **分拣锁定**：订单按批次锁定数量，写事务使用 `BEGIN IMMEDIATE` 串行化；
  两名员工并发分拣同一批次时**恰好一单成功**，另一单收到 `lock_conflict`。
  取消订单释放锁定并记「订单取消」告警。
- **称重去重**：电子秤读数携带 `(设备编号, reading_token)` 唯一令牌，
  重复提交被 `duplicate_weighing` 拒绝。
- **补录称重**：新增一条「补录」称重记录，**原始入池值与设备永久保留**；
  差异生成「待确认」挂账，供应商确认前不改任何账，差异超 2% 触发称重差异告警。
- **损耗**：必须关联原批次，数量不得超过可锁余量；累计死亡率超品种阈值
  （青斑鱼 5%、花蟹 6%、对虾 8% 等）触发严重告警；分拣+损耗耗尽即自动出清。
- **供应商权限**：差异单 / 结算单只能由归属供应商凭 token 确认，
  跨供应商返回 `403 forbidden`，无效凭证返回 `401`；结算确认后来源批次置为
  已结算，关联池内批次重量永久锁定（再补录返回 `settled_locked`）。
- **对账单金额**：按 `(入池重量 − 损耗重量) × 品种单价` 计算，
  仅并入「已确认」差异金额。

## 本地设备适配器

`seafood/devices.py`

- `ScaleAdapter`：模拟电子秤，带传感器抖动；每个读数生成全局唯一 token。
- `WaterProbeAdapter`：模拟水温/溶氧探头，支持 `normal / heat / low_oxygen`
  三种工况；监控基线按槽内在养品种的适温中值与溶氧下限自动设定。
- `seafood/monitor.py`：进程内守护线程（默认 5 秒）采样落库，
  超阈值生成告警，缺氧同时生成「损耗提醒」，同槽同类 open 告警卫重复。

## 测试

```bash
python3 -m unittest tests.test_platform -v
```

覆盖：容量校验（含报损释放）、盐度/混养校验、批次锁定与取消释放、
已结算批次重量锁定、并发分拣仅一单成功、称重去重、补录原值保留、
损耗计算与死亡率告警、供应商跨户权限（401/403）、监控升温/缺氧检出。

## 目录结构

```
seafood/
  db.py        # SQLite 表结构与线程安全事务（BEGIN IMMEDIATE）
  services.py  # 领域服务：入池/补录/损耗/订单/结算全部规则
  devices.py   # 电子秤 + 水温/溶氧探头模拟适配器
  monitor.py   # 进程内探头轮询任务与告警/损耗提醒
  seed.py      # 演示基础数据与入池/分拣/报损样例
  app.py       # HTTP API + 静态页面服务（标准库）
  static/      # index.html / app.js / styles.css（海蓝·白·番茄红）
tests/
  test_platform.py
run.sh         # 一键演示启动
```
